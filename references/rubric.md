# 《心愿词典》评分标准与硬门槛

## 一票否决

- 抄袭其他自媒体稿件，或把低质量 AI 成稿直接充当正式投稿。
- 数据造假、文献造假、图表造假、引文造假。
- 缺少参考文献，或提交时无法同时交出自己的参考文献清单。

## 1. 选题与文献采用（20%）

- `5%`：选题贴近生活，或具有明确科学意义；所介绍的理论属于经典心理学理论。
- `10%`：参考经典理论的原实验、原文献，通常优先国外原文。
- `10%` 细则：
  - 若存在国外原始论文却只参考国内论文，此项最多拿一半。
  - 若完全未参考论文，只依赖国内自媒体或二手转述，此项不得分。
- `5%`：文章开头通过具体场景、扎心问题或流行文化梗切入，能抓住读者。

## 2. 实验解析 Experiment（40%）

- `15%`：至少给出两张图表，并配图注/表注解释。
- 图表最低配置：
  - 图表 1：自变量、因变量、条件或范式结构表。
  - 图表 2：原实验中的数据图或数据表。
- 图表来源要求：
  - 尽量直接来自原论文。
  - 若原图为英文，应基于原图做中文翻译，或依据原始数值重建中文表格。
- `10%`：清楚、准确、易懂地描述实验过程，并额外解释控制混淆变量的方法，如实验平衡、掩饰目的、欺骗被试、随机分配等。
- `5%`：对数据结果有准确分析，而不只是口头复述“支持假设”。
- `10%`：在原实验之外补充拓展内容，例如后续改进范式、近期研究进展、争议点或局限。

## 3. 理论介绍与实践转化（25%）

- `10%`：`Thinking` 部分完整介绍理论本身，包括概念、机制、边界与适用条件。
- `10%`：`Pleasure` 部分讨论理论在关系、学习生活、职场发展、自我成长、商业营销等场景中的应用，并提供能执行的行动建议。
- `5%`：`Summary` 负责恰当总结与升华，不空泛，不强行拔高。

## 4. 格式与排版（15%）

- `5%`：严格遵循固定结构，一级标题顺序必须是 `导言 -> Experiment -> Thinking -> Pleasure -> Summary -> Reference`。
- `5%`：二级标题统一使用 `»`。
- `5%`：排版要图文并茂。
- 排版细则：
  - 核心概念、关键结论、重要提醒要加粗。
  - 图和表以及对应图注、表注默认居中。
  - 图表区域不做左缩进和首行缩进。
  - 文字过密的部分需要配图或拆分。
- `5%`：参考文献严格遵循 APA 格式。

## 使用提醒

- 这套 rubric 奖惩很明确，写作时优先满足硬约束，再追求文风。
- 如果某项证据暂时拿不到，宁可明确写出“待核验”，也不要编造后补。
