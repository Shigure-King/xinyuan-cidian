# 《心愿词典》Word 版式规范

本规范基于 `心愿词典Vol.8.docx` 的实际渲染结果提炼。该样稿存在较多“直接格式”操作，因此复现时应优先模仿视觉效果，而不是机械复用原文件里的样式名。

## 使用优先级

- 用户给了新的 DOCX 样稿时：新样稿优先于本规范。
- 用户只说“按《心愿词典》原来的 Word 风格排版”时：默认以本规范为基线。
- 如果文字内容与版式发生冲突：先保留栏目层级和可读性，再做局部压缩。

## 页面设置

- 页面：A4 纵向。
- 页边距：
  - 上下约 `72 pt`。
  - 左右约 `90 pt`。
- 页眉页脚距离：
  - 页眉约 `42.55 pt`。
  - 页脚约 `49.6 pt`。
- 图片使用嵌入式 `inline` 摆放，不使用浮动环绕。

## 标题区

- 总标题单独成段，居中。
- 标题格式：`心愿词典第{期数}期丨{主题}`。
- 若期数未知，可退化为 `心愿词典丨{主题}`。
- 总标题视觉基线：
  - 字体：`微软雅黑`
  - 字号：`16 pt`
  - 字重：加粗
  - 段前段后：约 `8 pt`
- 标题下方可接 1 到 5 段居中导入语，用来制造悬念、问题或场景。
- 这些导入段落不做首行缩进，保持居中，和正文形成明显对比。

## 正文章节

- 一级内容段落顺序固定：
  - `导言`
  - `Experiment`
  - `Thinking`
  - `Pleasure`
  - `Summary`
  - `Reference`
- 在 Word 成稿里，这些英文分节标题通常单独成段、左对齐。
- 分节标题视觉基线：
  - 字体：`微软雅黑`
  - 字号：`14 pt`
  - 字重：加粗
  - 不做首行缩进
- 正文段落视觉基线：
  - 中文主字体：`微软雅黑`
  - 默认字号：接近 Word `Normal` 的 `11 pt`
  - 左对齐
  - 首行缩进：约 `21 pt`，相当于两个中文字符
  - 段前段后：约 `8 pt`
- 结论句、关键词、核心反直觉点可局部加粗，但不要整段满篇加粗。

## 图像与图注

- `Vol.8` 样稿含 5 张嵌入式图片，说明该栏目接受“导入配图 + 数据图/示意图”混排。
- 推荐做法：
  - 开篇配图可略小，宽度约 `300 pt` 左右。
  - 实验图和示意图可接近正文宽度，常见宽度约 `350-415 pt`。
- 图前后各留一段呼吸位，不要让图片贴着密集正文。
- 图注单独成段，通常左对齐，不做首行缩进。
- 图注命名采用 `图1 ...`、`图2 ...`。

## 表格

- `Vol.8` 样稿默认使用 `Plain Table 3` 一类的简洁表格风格，而不是粗网格重边框。
- 表格标题单独成段，左对齐，例如：
  - `表1 变量分析及其操作性定义`
  - `表2 长实验中，不同被试的实验反馈和他们后续愿意重复的实验`
- 表格正文经验规则：
  - 表头与行标签优先用 `黑体`，便于和正文区分。
  - 英文、数字或变量代码可使用 `Times` / `Times New Roman` 系列。
  - 单元格内容整体以居中为主。
- 若原始论文的表格结构复杂，优先保留信息完整度，其次再追求表格美观。

## Reference 与署名

- `Reference` 分节标题单独成段，左对齐，`14 pt` 微软雅黑加粗。
- 参考文献正文单独成段，左对齐，不做首行缩进。
- 即使是英文 APA 参考文献，样稿里也并未强制切换为纯英文正文字体；若整体观感统一，可继续沿用正文字体。
- 末尾署名区右对齐。
- `Vol.8` 样稿把署名合并在一个右对齐段落中：
  - `文案丨学术部 {姓名} 排版丨媒体部 {姓名} 责任编辑丨张李兵 谢宗含`
- 若内容较长，也可拆成 2 到 3 个右对齐段落，但应保持同一视觉区域。

## 实施建议

- 先写完整内容，再做版式映射，不要一边写一边频繁改格式。
- 若从 Markdown 转 Word：
  - 先放总标题与导入区。
  - 再落分节标题。
  - 最后统一处理正文缩进、表格、图片和署名。
- 原样稿的样式名并不稳定，例如只有标题用了自定义 `样式1`；因此复现时建议直接设置段落与字体属性，而不要依赖样式名匹配。
